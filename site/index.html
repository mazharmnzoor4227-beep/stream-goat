📺 On a TV with the Downloader app

The easiest way on Android TV, Google TV, Fire TV and TV boxes: no computer, no USB stick.

  1. Install Downloader (by AFTVnews) from the TV's app store (Google Play or the Amazon Appstore).
  2. Let it install apps: Google TV / Android TV: Settings → Apps → Security & restrictions → Unknown sources → Downloader → On. Fire TV: Settings → My Fire TV → Developer options → Install unknown apps → Downloader → On (no Developer options? Settings → My Fire TV → About → press the device name 7 times).
  3. Open Downloader and type this address in the box, then press Go:
    sherazi5110.github.io/stream-goat/tv
  4. When it has downloaded, press Install, then Open. Downloader offers to delete the file afterwards: press Delete, it isn't needed any more.

It always gets the newest version. If the TV says "App not installed", uninstall the old Stream Goat first (back up first: Settings → Updates and backup), or type sherazi5110.github.io/stream-goat/apk instead (works on every device, bigger download).

Step-by-step help for every device: install guide. iPhone and iPad: use the web version and add it to your home screen.

Updating on Android? Uninstall the old version first. To keep your extensions, lists and settings, back them up before you uninstall (Settings → Updates and backup: Google Drive, or Back up to a file) and restore after installing.

Google Drive backup

Sign in with a code (on TVs too) or one tap on a phone. Settings, profiles, lists, history, extensions and add-ons are backed up every 5 minutes, one backup per device: restore your phone's on your TV.

A streaming-service look, Continue Watching, backups in your browser and Google sign-in. The player has subtitles, audio tracks, speed 0.5×–2×, quality and sources.

On Android TV, scan a QR code and send add-on and repository links from your phone. No typing with the remote.

Downloads like IDM

8 connections at once, choose the source and quality, and pick up after a pause or a dropped connection.

More extensions work

Every extension in the official repository list was checked: 577 of 587 load fully on Android.

Faster and steadier

Quicker start on TV boxes, videos start sooner, no more freezing on slow servers, and a report if the app ever closes.
